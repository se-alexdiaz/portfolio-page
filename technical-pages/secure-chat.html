Secure Chat

A simple end-to-end encrypted chat app, built to understand how E2E cryptography actually works. No backend, just one page simulating two users side by side using the browser's built-in Web Crypto API.

Overview

  • 1- Each person generates an ECDH key pair (P-256). Private key never leaves their side. Public key is meant to be shared.
  • 2- They swap PUBLIC keys. This can happend in the open.
  • 3- Each ones combines their own private key + the other's public key. ECDH's trick: both combinations produce the SAME 256-bit number. An eavesdropper who saw both public keys compute it.
  • 4- That raw shared number is not a good key on its own, so it is run through HKDF to stretch/clean it into a proper AES-256 key.
  • 5- Every message is encrypted with AES-GCM using a fresh random IV. GCM also produces an authentication tag, so any modification in transit is detected and the message is rejected.
